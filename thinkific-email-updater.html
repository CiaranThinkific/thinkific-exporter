Email Updater

Looks up each user by Incorrect Email (GraphQL userByEmail), then updates them to Correct Email via REST PUT /users/:id.

Instructions

  1. Add your API token and save it.
  2. Download the CSV template and fill in Incorrect Email / Correct Email.
  3. Upload a small test CSV first, then run the full file.
  4. Download results when finished (user id, emails, status, timestamp).
