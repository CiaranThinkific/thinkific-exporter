User Deleter

Uses GraphQL beta (stable has no lastSignInAt). Pages all users, filters by last sign-in in the browser, then deletes via REST.

Instructions

  1. Add your API token.
  2. Pick a last-sign-in rule, then Search Users.
  3. Remove = drop from list only. Delete = REST delete.
  4. Delete All Listed deletes every remaining Pending user.
  5. Download the results CSV when finished.
